What it is

A design critic that lives inside Claude

1

A plugin for Claude Code. Installed once, it gives Claude a skill: a method and a knowledge base about interfaces.

2

You talk to Claude as usual. Show a screenshot, a Figma link, code or a staging URL, and say what you need.

3

Claude answers like a senior design reviewer: a verdict, findings, and for each one the rule and the reason.
